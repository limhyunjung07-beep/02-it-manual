선생님 TIP단계별 선생님 TIP 모음권장 시간 · 수업 전 준비 · 자주 막히는 곳을 활동별로 모았어요. 제목을 누르면 그 활동으로 가요.
1-1로그인▶
권장 시간
첫 로그인은 10~15분 · 회원가입이 안 된 학생이 많으면 1차시를 따로 잡아요
수업 전 준비
  • 담임 선생님께 학급별 회원가입 현황을 미리 받아요
  • 만 14세 미만은 법정대리인 동의가 필요해요 — 가정통신문을 먼저 보내요
  • 반마다 진로 도우미를 정해 두면 도움을 나눌 수 있어요
자주 막히는 곳
  • [교직원] 칸을 눌러 로그인이 안 돼요 → [학생]의 로그인
  • 아이디·비밀번호 분실 → 원패스 [아이디/비밀번호 찾기]
  • 개인정보 동의에서 [비동의]를 누르면 로그아웃돼요
1-2검사 전 컨디션 관리▶
권장 시간
설명 영상 약 2분 + 따라 하기 2분, 모두 5분 이내
수업 전 준비
  • 스피커 소리와 전체 화면 재생을 미리 확인해요
  • 검사 시작 직전에 실시하면 효과가 좋아요
자주 막히는 곳
  • 억지로 깊게 쉬다가 어지러워해요 → 멈추고 평소처럼 숨 쉬게 해요
  • 웃거나 떠드는 분위기 → 눈을 감고 손을 가슴에 얹게 해요
1-3진로심리검사 실시▶
권장 시간
검사 1개와 결과 PDF 저장·업로드까지 1차시(45분)를 권장해요
수업 전 준비
  • 1-1 로그인을 먼저 끝내요
  • 결과지 PDF 저장 방법(프린터 → PDF로 저장)을 화면으로 먼저 보여 줘요
  • 직업흥미검사(H)는 커리어넷 로그인·본인 인증이 필요해요
자주 막히는 곳
  • 인쇄 창에서 대상을 ‘PDF로 저장’으로 바꾸지 못해요
  • 저장한 PDF 파일 위치를 못 찾아요 → 파일 이름을 미리 정해 주기
  • 직업흥미검사(H) 결과는 꿈it(잇)다에 올라가지 않아요
1-4심리검사 결과정리▶
권장 시간
활동지 작성 1차시를 권장해요
수업 전 준비
  • ‘나의 진로 보물지도’ 활동지를 인쇄해요(PDF·HWP 내려받기)
  • 1-3 검사 결과가 저장·업로드되었는지 확인해요
자주 막히는 곳
  • 검사 결과 화면을 못 찾아요 → 검사 카드의 [검사결과 보기]
  • 검사를 1개만 한 학생 → 해당 칸만 채우고 나머지는 다음 시간에
1-5채팅으로 황금지점 찾기▶
권장 시간
챗봇 대화와 직업 고르기까지 1차시를 권장해요
수업 전 준비
  • 1-4 활동지를 먼저 완성해요
  • 챗봇 링크가 수업 기기에서 열리는지 미리 확인해요(구글 로그인이 필요할 수 있어요)
자주 막히는 곳
  • 이름·학번 같은 개인정보를 챗봇에 넣어요 → 넣지 않게 안내
  • 추천 직업을 그대로 고르기만 해요 → 활동지의 탐색할 직업 3순위를 직접 쓰게 해요
2-1진로 직업탐색▶
권장 시간
20~30분
수업 전 준비
  • 1-5에서 희망 직업을 고르고 꿈it(잇)다에 선택했는지 확인해요
  • 체험 신청은 선생님과 상의하도록 미리 안내해요
자주 막히는 곳
  • 고른 직업이 안 보여요 → [나의 희망직업 변경하기]
  • [진로]·[진학] 탭을 헷갈려요 → 2-1은 [진로] 탭
2-2진로 진학탐색▶
권장 시간
20~30분 · 2-1과 이어서 하면 좋아요
수업 전 준비
  • 2-1과 같은 화면의 [진학] 탭을 써요
  • 관심 학교는 학교 홈페이지·입학설명회로 더 알아보도록 안내해요
자주 막히는 곳
  • 학교추천이 너무 많아요 → 지역·학교유형으로 먼저 거르기
  • 학과 이름만 적고 끝내요 → 준비방법 중 지금 할 일 1가지 적기
2-3진로로드맵(직업정보)▶
권장 시간
20~30분
수업 전 준비
  • 학생마다 알아볼 직업을 1~2개 미리 정해요
  • 직업인 영상은 이어폰을 준비해요
자주 막히는 곳
  • 직업 이름이 검색되지 않아요 → 비슷한 이름이나 직업군으로 검색
  • 읽기만 하고 끝내요 → 알게 된 점·더 궁금한 점을 한 줄씩 쓰게 해요
2-4진학로드맵▶
권장 시간
20~30분 · 고입을 앞둔 학년에 특히 좋아요
수업 전 준비
  • 학년에 맞춰 중학교·고등학교·대학교 중 어디부터 볼지 정해요
  • 고입 일정·전형은 학교 홈페이지와 입학설명회로 꼭 확인하게 해요
자주 막히는 곳
  • 학교 정보만 보고 끝내요 → 나의 진학 경로를 한 줄로 그려 보게 해요
2-5모의면접기▶
권장 시간
질문 1개에 생각 30초 + 답변 1분 · 한 학생에 5~10분
수업 전 준비
  • 모의면접기는 Claude 페이지라 선생님 계정으로 열어 화면에 띄워 써요
  • 녹화하려면 카메라·마이크가 되는 노트북을 준비해요
  • 지원 학교의 입학전형 요강으로 면접 방식을 먼저 확인해요
자주 막히는 곳
  • 답을 외워서 말해요 → 결론 → 이유 → 경험 → 다짐 틀로 내 말로
  • 면접 방식은 학교와 해마다 달라요
3-1상담게시판 상담▶
권장 시간
학생 글 쓰기 10~15분 · 답변은 선생님이 따로
수업 전 준비
  • 진로심리검사(1-3) 응시 후 신청하도록 안내해요
  • 학생용 계정으로 로그인해야 글을 쓸 수 있어요
  • 답변 초안은 3-2 상담게시판용 챗봇을 활용해요
자주 막히는 곳
  • 고민을 너무 짧게 써요 → 희망 직업 + 궁금한 점 한 가지로 쓰게 해요
  • 개인정보(연락처 등)를 쓰지 않도록 안내해요
3-2상담게시판용 챗봇▶
권장 시간
예시 함께 보기 10분
수업 전 준비
  • 상담 예시 파일을 미리 열어 봐요
  • 답변 챗봇에는 학생 이름·반·번호를 지우고 고민 내용만 넣어요
자주 막히는 곳
  • 예시 답변을 그대로 따라 써요 → 내 희망 직업과 궁금한 점으로 바꾸게 해요
  • 챗봇 답변은 꼭 확인하고 다듬은 뒤 올려요
※ 수업 전에 해당 활동의 TIP을 한 번 훑어보고 들어가면 수업이 끊기지 않아요.
